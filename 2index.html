À Propos

Ce calendrier almanach vous présente les jours fériés, les fêtes du calendrier grégorien, les vacances scolaires par zones et les saisons astronomiques pour la France métropolitaine.

Les données des vacances scolaires sont basées sur les informations du Ministère de l'Éducation Nationale.

Les jours fériés listés sont les onze jours fériés légaux en France.

Zones scolaires :
Zone A : Besançon, Bordeaux, Clermont-Ferrand, Dijon, Grenoble, Limoges, Lyon, Poitiers
→ Villes principales : Besançon, Bordeaux, Clermont-Ferrand, Dijon, Grenoble, Limoges, Lyon, Poitiers

Zone B : Aix-Marseille, Amiens, Caen, Lille, Nancy-Metz, Nantes, Nice, Orléans-Tours, Reims, Rennes, Rouen, Strasbourg
→ Villes principales : Marseille, Amiens, Caen, Lille, Nancy, Metz, Nantes, Nice, Orléans, Tours, Reims, Rennes, Rouen, Strasbourg

Zone C : Créteil, Montpellier, Paris, Toulouse, Versailles
→ Villes principales : Paris, Versailles, Créteil (Île-de-France), Montpellier, Toulouse
